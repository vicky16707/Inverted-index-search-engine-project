# Inverted Index Search Engine

A simple search engine project that uses an **Inverted Index** to search for words in a collection of documents.

## Features

* Create an inverted index from documents
* Search for words quickly
* Display documents containing the searched word
* Simple and efficient searching

## How It Works

The inverted index stores each word along with the documents where it appears.

Example:

```text
hello → document1, document3
world → document2, document3
```

When a user searches for a word, the system looks up the word in the index and returns the matching documents.

## Technologies Used

* Python
* Data Structures
* Inverted Index

## How to Run

```bash
python main.py
```

Enter a word when prompted to search the documents.
